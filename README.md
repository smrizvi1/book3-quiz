# Book 3 Quiz

Mastery-based MCQ practice for the madressa Book 3 sample questions (45 questions).

- A question answered correctly first time retires immediately.
- A question answered wrong must then be answered correctly **twice in a row** before it retires.
- Answer options are reshuffled every single time a question is shown.
- Finishing all 45 records the attempt; restarting begins the next attempt.

Progress is stored per-device in `localStorage`. Installable as a home-screen app; works offline.

To edit or add questions, see `questions.js`.
